# 抽检有数
有限批量随机抽查情景计算器：给定总份数N、假设问题份数D、抽查数n、目标发现概率q，计算至少发现1份问题的概率，反推最小n，生成均匀无放回编号并导出空白检查表。

静态本地计算，无外部依赖/请求。`node build.cjs` → index.html；`node --test tests/core.test.cjs`；`python3 -m http.server 8814`。

P0=C(N-D,n)/C(N,n)，取较短的n/D连乘进行对数计算，p1=-expm1(logP0)。n>N-D才称数学确定；极小尾部不舍入成绝对0，近1不舍入成绝对100。最小n二分查找。目标q最多1位小数，先转整数千分比的遗漏目标，规避99.9%边界消去误差。N最多100000，D/n为整数0–N。

Floyd算法选择子集；WebCrypto Uint32拒绝采样产生无模偏随机整数，号码排序1..N。最多生成2000份；UI仅显示前100，CSV完整。全部编号需用户先映射到真实对象；软件不记录真实已检结果，CSV结果栏初始为空。

修改输入即清空旧名单并禁用导出，需重新计算。JSON保存配置及名单；导入严格检查版本、字段、数量、范围、排序和唯一性。恢复不重新随机。PNG/Markdown为方案，JSON为备份，CSV为执行用空白检查表。

边界：D是情景假设，不估计未知缺陷数。等概率不放回、抽中问题必能识别。便利抽样/审核漏看/实际抽查执行均不被验证；未检出不能证明整批合格，不是法定验收标准。无科学打分、虚构用户案例或实测质量结论。
